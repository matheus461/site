1.1 Componentes Internos

1.1.1 CPU

A CPU (Unidade Central de Processamento) é o principal componente do computador, responsável por processar as instruções de programas e executar os cálculos necessários para as operações.

1.1.2 Armazenamento

Os dispositivos de armazenamento, como HDDs e SSDs, são usados para armazenar dados de forma permanente ou temporária no computador.

1.1.3 Memória

Memória RAM é a memória volátil que armazena dados temporários enquanto o computador está em funcionamento. Ela permite que o processador acesse rapidamente os dados necessários.

1.1.4 Fonte de Alimentação

A fonte de alimentação converte a energia elétrica em uma forma que os componentes internos do computador possam usar.

1.2 Componentes Externos

1.2.1 Teclado

O teclado é um dispositivo de entrada usado para inserir dados no computador, como texto e comandos.

1.2.2 Monitor de Vídeo

O monitor de vídeo exibe as imagens e os dados processados pelo computador, permitindo a interação visual do usuário com o sistema.

1.2.3 Mouse

O mouse é um dispositivo apontador utilizado para mover o cursor na tela e interagir com a interface gráfica do sistema operacional.

1.2.4 Impressora

A impressora é um dispositivo de saída usado para imprimir documentos e imagens do computador em papel.

1.2.5 Plotter

O plotter é uma impressora especializada em gráficos, desenhos e grandes imagens com alta precisão.

1.2.6 Scanner

O scanner é um dispositivo de entrada que converte documentos físicos em imagens digitais.

1.2.7 Gabinete

O gabinete é a estrutura que abriga os componentes internos do computador, oferecendo proteção e organização.

1.2.8 Web Cam

A WebCam é uma câmera digital usada para capturar imagens e vídeos, geralmente para videoconferências ou transmissões ao vivo.

1.2.9 Caixas de Som

As caixas de som são dispositivos de saída que reproduzem áudio processado pelo computador.

1.2.10 Microfone

O microfone é um dispositivo de entrada usado para captar som e convertê-lo em sinais digitais.

1.2.11 Head Set

Os headsets são fones de ouvido com microfone integrados, utilizados para comunicação por voz e reprodução de áudio.

1.3 Interfaces de Entrada e Saída

1.3.1 Interfaces Sem Fio

As interfaces sem fio, como Wi-Fi e Bluetooth, permitem a comunicação sem o uso de cabos.

1.3.2 Áudio

Interfaces de áudio permitem a entrada e saída de sinais sonoros, como entradas de microfone e saídas para fones de ouvido e caixas de som.

1.3.3 Rede (Ethernet)

Ethernet é uma tecnologia de rede que usa cabos para conectar dispositivos em uma rede local (LAN).

1.3.4 VGA

A interface VGA (Video Graphics Array) transmite sinais de vídeo analógicos para monitores.

1.3.5 HDMI

HDMI (High-Definition Multimedia Interface) é uma interface digital que transmite áudio e vídeo de alta qualidade entre dispositivos.

1.3.6 USB

A interface USB (Universal Serial Bus) é usada para conectar dispositivos como teclados, mouses, impressoras e armazenamentos externos ao computador.

2. Grandezas Elétricas

2.1 Potência Elétrica

A potência elétrica é a taxa na qual a energia elétrica é consumida ou gerada. Sua unidade de medida é o watt (W).

2.2 Tensão Elétrica

A tensão elétrica é a diferença de potencial entre dois pontos de um circuito. Sua unidade é o volt (V).

2.3 Corrente Elétrica

A corrente elétrica é o fluxo de elétrons através de um condutor. Sua unidade de medida é o ampère (A).
